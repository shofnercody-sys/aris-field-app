# ARIS Field

Offline field data collection for agricultural research trials — a companion to the ARIS desktop app.

**Use it:** open the app link on your phone → Share → **Add to Home Screen**. After that it launches
like a normal app and works fully offline.

- Load a trial from a CSV exported by desktop ARIS (Assessment Entry → ⬇ CSV), or set one up manually.
- Enter assessment values plot by plot; leave cells empty when there's no data point.
- Keep a field log (sprays, irrigation, scouting) and quick notes.
- Export everything as CSV via the share sheet (Mail / AirDrop / Files). On the desktop,
  Assessment Entry → **⬆ Import CSV** merges the values into the trial by plot number.

**Privacy:** this page is a static app shell. All trial data stays in your phone's local storage —
nothing is uploaded anywhere.
